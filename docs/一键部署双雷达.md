# Windows 一键部署双雷达

适用于已有 Ubuntu 22.04、ROS 2 Humble、手机网关服务、Foxglove 和串口配置的 sky 用户 RK3576。不是系统镜像烧录器，也不烧录 F407。默认导出 Git 标签 v2.0.1，不包含未提交代码。

先停止手机建图/导航任务，关闭 24V 电机动力。若相机或其他 ROS 程序独立运行，先停止其服务。

Windows PowerShell：

```powershell
cd G:\work\ROS2\RK3576_deploy\rk3576_footbath_ws_source
powershell -ExecutionPolicy Bypass -File .\scripts\deploy_dual_lidar.ps1 -MotorPowerOff
```

异地连接追加 `-HostAlias footbath-rk-remote`。指定提交或版本追加 `-Version v2.0.1`。`-MotorPowerOff` 是操作者对实际断开动力的声明，脚本不能检测物理开关。

仅打包检查（不连接小车）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\deploy_dual_lidar.ps1 -PackageOnly
```

SSH 会交互提示 sudo 密码，不保存密码。优先复用板端 Git 中固定版本的 sllidar_ros2；没有该 Git 对象才下载依赖，需要网络。不自动更改 apt、网络、设备树、机器配置或相机代码。

脚本检查路径、挂载点、可用空间、版本和包哈希，停止现有服务后，将旧工作区改名保留，在原正式路径重新编译。保留工作区 maps 和旧源码目录里的地图，不沿用 build/install。构建或启动失败时恢复旧工作区，服务保持停止，避免自动恢复旧运动任务。SSH 中断时必须按终端日志确认实际状态，不可盲目重复执行。

成功只表示手机网关和 Foxglove 进程连续运行 20 秒。仍需保持动力关闭，在网页手动启动双雷达建图验证雷达、里程计、地图，之后再现场运动验收。

部署版本写在板端 `/home/sky/rk3576_footbath_ws/DEPLOYED_VERSION.txt`。历史工作区和失败工作区不自动删除，会占磁盘；确认不需要后再清理。若预检查后被其他进程阻塞，原工作区仍在，但已停止的服务需要手动启动。

本工具首次交付仅作本机语法、打包和静态检查，尚未在 RK 实际执行完整部署。原机已验证程序不会被本次脚本开发自动替换。
