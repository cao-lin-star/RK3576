# 三路超声近障模式（2026-09-23）

本版本替代三路玻璃分类方案。前向保留稳定版20cm停车/28cm解除；左右采用探头测距12cm门限。
有效新鲜左右回波>12cm不触发停车、不新增障碍点；无回波不标记障碍；故障/过期仍保留故障停车。
左右朝向±45°，沿波束内缩车体外沿约10cm，基于0.22m半径设置x/y为0.084853m。
12cm是探头到障碍的距离，不是车体外沿到障碍的距离。

保留80ms前-左-前-右轮询、66ms长回波修复、0x08三路状态、0x09/0x0A开关确认及10Hz来源遥测。
F407和RK必须配套更新。开关仍只在空闲选择、静止确认；重启网页服务/F407默认开启。

自动建图、普通导航、返航导航段：近障触发后先取消导航并静止，最多3秒等待3次独立新回波；
回波必须在停车之后采集、间隔≤0.6秒，位置变化≤2.5cm，使用采集时刻TF，缺失TF不以最新位姿替代。
确认后保留原后方雷达检查和后方地面安全假定，以0.03m/s直退，最多0.15m/6秒，不盲目转向。
前方恢复至28cm、左右>12cm后，还需让车体中心距确认点至少33cm（车体+小障碍+栅格余量），
避免刚过12cm就启动Nav2但车体仍在新禁区内；无法在有界直退内满足时停车提示。

确认点在本监督器会话内保留，标记半径4cm，不画扇形；距离6cm内记录合并且不扩大。
同一点最多完成2次自动恢复；再次受阻停止。局部与全局hazard层都确认写入后才继续原任务。
近障点不写入永久PGM地图，也不写入持久化cliff sidecar；结束/重启监督器（含建图切定位）清除本次近障记忆。
已确认点不会因新测距>12cm或关闭左右开关而在同一监督器会话内被清除。

网页侧向总开关不影响前向、ToF或双雷达。基站/地图绑定、独立初始化返回点及导航/返航台阶恢复保留。
玻璃只有被超声实际检测到才可按普通障碍处理；无回波不能保证玻璃不存在。
