### V3.0.0 具体更新

- **三路超声保护**：前超声20cm触发、28cm必要解除；35cm仅作为优先余量。左右有效测距≤12cm触发保护，网页保留总开关和底盘确认。保留长回波采集时序处理。
- **停稳确认障碍**：暂停导航、确认静止后采集多次新回波，以采集时刻位姿记录普通障碍；不判断玻璃材质。已确认记录进入全局/局部代价地图，与地图配套保存；清除需满足融合检查或人工编辑。
- **探索与恢复**：受阻探索点按当前重试规则跳过，继续选择其他可达点；无进展时先收回导航控制权检查起步空间。允许安全掉头、沿已走曲线退出，以及朝向合适时无需掉头正向退出。
- **恢复连续性**：通信或可恢复故障先停车，恢复后继续原任务；近障复核不因一次远回波直接推翻近障；补齐恢复和地图确认期间的退路记录。没有安全证据时保留任务停车，并显示退出被拒绝的原因。
- **TOF恢复**：区别失联和仍有通信的近距无效测量，仅在原有退路、后方与地面条件许可时有界后退；有效测距下限15mm，防跌落阈值28cm。
- **地图网页**：绿色探索点/路径、红色受阻区域、障碍记录；支持画线增加/擦除补充障碍。建图编辑前暂停，生效后继续；地图用于导航后仍可编辑保存。
- **任务时限**：默认30分钟，网页显示 RK 监督器实际剩余预算；刷新不重置。手动暂停仍计时，已有恢复等待按各分支扣除。无可达探索点须持续确认，任务时限到达与探索完成是不同状态。
- **基站与起点**：基站随地图保存；手动初始化位置是独立返回目标。保留普通导航、返航台阶恢复及基站出入站动作。
- **语音**：CI1302 串口，唤醒词“妮妮”；支持“回到基站”“回到起点”“开始自动建图”和状态播报。启动建图指令受空闲状态门控；语音模块固件须与协议表配套。

## 当前数据流

```text
高位雷达 /scan_high + 低位前135° /scan_low_front
  → 时间配对与帧间运动补偿 → /scan_mapping_fused → SLAM Toolbox
  → Nav2 全局/局部激光障碍层
高位 /scan_high → AMCL（加载已有地图导航）
前/左/右超声 → F407 独立保护 + RK 停稳确认 → 补充障碍层
双 TOF → 地面保护与有界恢复判断
Nav2 / 恢复控制 → 安全限速、租约和命令仲裁 → 串口桥 → F407
```

建图可在启动前选择高位单雷达回退模式。低位雷达保留物理前方135°并过滤车体；超声不直接生成 SLAM 激光地图，补充障碍由 sidecar 和 HazardLayer 管理。

## 获取与构建

在 RK 的 Linux ext4 工作空间构建，勿复制 Windows/WSL 生成的安装产物上车。

```bash
git clone https://github.com/cao-lin-star/RK3576.git rk3576_footbath_ws
cd rk3576_footbath_ws
git checkout V3.0.0
vcs import src < dependencies.repos
bash scripts/build.sh
source install/setup.bash
```

Slamtec 驱动固定于 `34300099fadfc772965962dec837bf436706188f`；`m_explore_ros2` 为本项目修改过的供应商源码，不应重新导入上游覆盖。

运行、接线与设备别名见 [`docs/RK3576编译与系统镜像烧录流程.md`](docs/RK3576编译与系统镜像烧录流程.md)、[`docs/RK3576与STM32F407接线表.md`](docs/RK3576与STM32F407接线表.md) 和 [`src/rk3576_footbath_mobile/README.md`](src/rk3576_footbath_mobile/README.md)。建图、导航应通过网页或明确的启动命令发起，构建本身不授权运动。

## 发布核对和已知限制

- 运行源码与板端比对一致（忽略 CRLF/LF）；一个语音测试文件采用本地更新版，不影响运行。源码清单见 `release-manifest.json`。
- 最近恢复衔接修改已通过258项相关测试并在RK完成构建部署。此版本是当前运行基线，不表示所有环境均已验收。
- 地图跳变问题等待复现；控制器 TF 查询时序问题尚未修复。
- 不具备完整的打滑识别；IMU 尚未融合进当前里程计；传感器盲区碰撞不会凭轮子空转自动写成永久墙体。
- 已走地面证据仍依赖里程计和TOF；雷达空旷不等于后方地面安全。无可用退出证据时仍会停车复核。
- 旧专题文档保留开发记录，部分阶段参数已被替代；当前行为以本 README 与源码为准。

## 版本管理

仓库只保存源码、配置模板、测试和说明。地图、语音固件、机器人凭据、日志、旧备份及 `build/install/log` 不提交。恢复旧版本时应同时选取匹配的底盘标签和 RK 标签，不混用恢复协议。
